# 🎮 Recovery Quest

> “Stop tracking your life like a spreadsheet. Start playing it like a game.”

https://recoveryquest.netlify.app/

Recovery Quest is an AI-powered, gamified health and recovery system that turns sleep, training, nutrition, and recovery tracking into a real-life RPG progression experience.

---

# 🧠 Problem Statement

Most health and fitness apps fail because they are:

- 📉 Boring and repetitive  
- 😴 Not engaging enough to maintain long-term use  
- 🧍 Lack meaningful motivation or guidance  
- 🔁 Focused only on logging, not improvement  

Users trying to improve fitness, recover physically, or build mental wellness habits often lose consistency due to lack of feedback, motivation, and structure.

---

# ⚔️ Solution

**Recovery Quest** transforms health tracking into an interactive game system.

It:

- Collects and analyzes user data (sleep, training, nutrition)
- Generates personalized recovery insights
- Calculates performance and consistency scores
- Provides AI-driven recommendations
- Includes an AI coach for real-time guidance

Instead of just showing data, it answers:

> “What should I do next to improve?”

Recovery Quest is designed like an RPG:

# 🧰 Technologies Used

- **HTML** → Structure of the application  
- **CSS** → UI styling & gamified design system  
- **JavaScript ** → Application logic & interactivity  
- **Local Storage / Client-side Data** → Persistent user data  
- **AI Integration** → Coaching, insights, and personalization  

No heavy backend required — designed to be fast and lightweight.
